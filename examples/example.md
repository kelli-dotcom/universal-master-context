# Example — one tiny project using this template

This is the whole shape of a project built from this master.

## The idea

A tiny list app. It shows three items, and lets you tick one off.

## The files

- `docs/START_HERE.md` — the idea above, written before any code.
- `src/index.mjs` — the code. (Not in this template. You create it.)
- `tests/smoke.test.mjs` — the check. Run it, it must pass.
- `CHANGELOG.md` — one entry, version 0.1.0, saying what shipped.

## How to check it

Run `node tests/smoke.test.mjs`. If it passes, the template is complete
and the idea is ready to build on. If it fails, it names the missing file.
